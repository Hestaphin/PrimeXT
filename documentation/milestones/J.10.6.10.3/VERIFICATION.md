# Verification evidence and limits

Reproduce from the PrimeXT root:

```sh
python game_shared/tests/verify_j10_6_10_3.py --ubsan --inherited --json /absolute/output/f3.json
```

Focused tests compile actual production format/template code with C++17, strict warnings, exceptions disabled and undefined-behavior sanitization. The SDK recording facade executes the real shared constructors, real scene shader bodies, real CCD handoff method and real DestroyActors method. It records setter calls and mirrors the documented kinematic/CCD flag transition; it provides **no simulation, collision or solver**. GUI adapters execute actual editor/template/settings methods with synthetic rigid/weighted Studio input; they provide **no real Qt/Win32 GUI or GL rendering**.

Final run: **7/7 F3 groups pass**, F2 5/5, F1 12/12, F0 8/8 and the broad inherited J.10.6.3 suite 46/46. Three complete Xash translation-unit syntax checks remain blocked by the supplied tree's missing generated `library_suffix.h`; the inherited checks report that limitation separately. No Xash native build is certified.

The final bundle's `evidence/f3_verified.json` and log are authoritative for the entire regression chain, including F2/F1/F0, complete PhysX-disabled pxmv syntax and inherited gameplay logic. Historical tests were updated to exercise valid v5 inputs; explicit obsolete-version rejection remains tested. The original v4 Barney reference is retained as historical source data, separate from active v5 test fixtures and new generated candidates.

Examples are regenerated by the production template factory and byte-compared by the verifier. Recorded Barney bounds contain no actual bind rotations or section-filtered mesh vertices. No actual-model optional integration was requested/run because the binary MDL is absent. No second humanoid/monster model is present. Source manifest, input/patch hashes and all ten byte/mode reconstruction routes accompany the bundle.
